# Optimized image set

These display-sized JPEG/PNG files are the runtime image sources for the prototype.
The original assets remain in their source folders as a high-resolution archive.

- Hero images are capped at 1920px on their longest side.
- Product images are capped at 1200px wide.
- Ambassador and editorial images are sized to their card layouts.
- Metadata is stripped from generated JPEGs to keep downloads smaller.
